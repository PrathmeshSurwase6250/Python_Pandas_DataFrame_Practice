# Python Pandas DataFrame Practice 🐍

This repository contains **115 practice questions across 6 levels**, designed to improve Python programming, Pandas DataFrame operations, and data analysis skills from beginner to advanced level.

## 📚 Levels and Topics

### Level 1: Python Fundamentals (Questions 1–15)
- Variables and data types
- Lists and dictionaries
- Conditional statements
- Loops and functions

### Level 2: DataFrame Basics (Questions 16–35)
- Creating and inspecting DataFrames
- Rows and columns
- Indexing and data types
- Summary statistics
- Unique values and exporting CSV files

### Level 3: Filtering and Sorting (Questions 36–55)
- Selecting rows and columns
- `iloc` and conditional filtering
- Multiple conditions
- `isin()` and sorting
- Finding highest and lowest marks

### Level 4: Data Analysis (Questions 56–75)
- Aggregation and calculations
- Creating new columns
- Pass/fail classification
- Attendance and performance categories
- Custom functions

### Level 5: Data Cleaning (Questions 76–95)
- Handling missing values
- Removing duplicate records
- Data type conversion
- Working with dates
- Data validation and cleaning functions

### Level 6: Advanced Pandas Practice (Questions 96–115)
- Python functions and lambda expressions
- `apply()` and `map()`
- String operations
- `np.where()` and `np.select()`
- Reusable DataFrame functions

## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Jupyter Notebook
- CSV datasets

## ⚙️ Installation

Install the required libraries using pip:

```bash
python3 -m pip install pandas numpy jupyter
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required Python libraries.
4. Open the Jupyter notebooks.
5. Start with Level 1 and progress through Level 6.
6. Practise each question before checking the solution.

## 🎯 Learning Objectives

- Strengthen Python programming fundamentals.
- Understand Pandas Series and DataFrames.
- Perform data selection, filtering, and sorting.
- Calculate statistics and create new columns.
- Handle missing values and duplicate records.
- Apply functions to real-world datasets.
- Develop problem-solving and data analysis skills.

## 📈 Practice Strategy

- Solve the questions in sequential order.
- Write your own code before checking examples.
- Test your solutions with different inputs.
- Review errors and understand why they occur.
- Practise regularly to improve your coding skills.

## 👨‍💻 Project Goal

The goal of this repository is to build strong practical knowledge of Python, Pandas, NumPy, and data analysis through structured, level-wise exercises.
